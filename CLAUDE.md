# Nekretnine Osijek: public web (frontend rewrite)

Personal real-estate tracker for Marko (Osijek-Baranja: Osijek i okolica, Antunovac, Bilje, Čepin,
Petrijevci, Valpovo). A Python tool on Marko's Mac collects every listing (portals, agencies, auctions,
tenders), scores it, sends WhatsApp alerts and publishes a static website on GitHub Pages:
https://markoboras0712.github.io/nekretnine-osijek-web

**Goal of this work:** replace the current plain HTML/CSS/JS frontend with the same stack Marko uses in
`~/zoetrope/apps/web`, keeping every feature and the data contract. The Python backend stays as it is,
except for the small publishing change described under "Deployment".

UI language is **Croatian** (hr-HR numbers: `120.000 €`, `1.193 €/m²`). Phone first, dark mode, accessible.

## Data contract: `podaci.json` (do not change field names without changing `objava.py`)

```ts
type Podaci = {
  generirano: string                 // "2026-11-07 13:56:20" (local time, Europe/Zagreb)
  naslov: string
  podrucje: Record<string, string[]> // općina -> naselja
  prosjeci: Record<string, [number, number]> // "mjesto|vrsta" -> [median €/m², count]; fall back "općina|vrsta"
  znacajke: Record<string, string>   // feature key -> Croatian label (garaza: "Garaža", ...)
  izvori: { naziv: string; radi: boolean; zadnji_uspjeh: string | null }[]
  skupine_izvora: { naziv: string; kako: string; svakih_min: number | null;
                    izvori: { naziv: string; radi: boolean; zadnji_uspjeh: string | null }[] }[]
  nekretnine: Nekretnina[]
}
type Nekretnina = {
  id: string                         // stable nekretnina id (used in marks, links, WhatsApp)
  vrsta: 'stan' | 'kuca' | 'zemljiste' | 'poslovni' | 'ostalo'
  opcina: string; naselje: string
  kvart: string                      // Osijek neighbourhood ('' if unknown or not Osijek)
  sobe: number | null; kat: number | null  // kat: -1 suteren, 0 prizemlje
  zadnji_kat: boolean
  znacajke: string[]                 // keys of Podaci.znacajke, extracted from ad text
  cijena: number | null; povrsina: number | null; zemljiste: number | null
  eur_m2: number | null; vs_prosjek: number | null  // % vs average (negative = cheaper)
  ocjena: number; prolazi: boolean; razlozi: string
  naslov: string; opis: string; telefon: string; slika: string; url: string
  izvori: { naziv: string; url: string; cijena: number | null; aktivan: boolean }[]
  od: string                         // first seen / published "YYYY-MM-DD HH:MM"
  nacin: 'oglas' | 'drazba' | 'natjecaj'
  rok: string                        // deadline "YYYY-MM-DD HH:MM" or ''
  jamcevina: number | null; prodavac: string; agencija: string
  zemljiste_vrsta: string; predmet: string  // predmet 'udio' | 'udio?' = co-ownership share
  aktivan: boolean
  cijene: [string, number][]         // price history, last 8
  pad: { eur: number; posto: number; datum: string } | null  // biggest drop in last 30 days
}
```
Fetch it at runtime (`fetch(basePath + '/podaci.json?t=' + 5-min bucket, { cache: 'no-cache' })`) so a
data-only deploy shows fresh data. Display place = `kvart` for Osijek when known, else `naselje`.

## Features that must survive the rewrite (reference: `~/Documents/nekretnine-osijek/web/app.js`)

**Layout:** hero (gradient, kicker with the six places, headline, live stats: active properties, number
of sources, "osvježeno prije X min"; buttons "Pogledaj ponudu", "Kako radi"), sticky header with search +
"Filteri (n)" + views, footer with freshness/broken sources. Page `/o-alatu` ("Kako radi"): stats,
5 steps, source groups from `skupine_izvora` with status dots and intervals, FAQ.

**Views (tabs with counts):** Novo za mene (active, not seen, not rejected), Sve, Favoriti
(favorit/za_obilazak/kontaktirano), Rokovi (active with future deadline, sorted by deadline, sort hidden),
Odbačeno, Nestali (inactive). First visit marks everything as seen.

**Search** (always visible): diacritics-insensitive (đ→d), all words must match, `-word` excludes,
`"phrase"`, prefix/stem matching (`garaze`→garaža, word ending vowel dropped for ≥4 chars), synonyms
(lift=dizalo, okućnica=dvorište=vrt, novogradnja=nova gradnja, trosoban=3 sobe, jug 2=jug ii, …), multi-word
place names auto-quoted, relevance (title/location hit 3, description 1) → sort "Najrelevantnije" while
searching (restore previous sort when cleared), highlighted matches + description snippet on cards,
suggestions while typing (places with counts, općine, features, types, room words, agencies); choosing a
place/feature/rooms/type applies a **filter**, agencies go into the query as a phrase.

**Filters** (chips show live counts = results if toggled, given all other filters; 0-count chips dimmed):
vrsta (default stan+kuća+zemljište), općina, kvart/naselje (top 12 + "Još N…"), price quick ranges
(do 80k, 80–120k, 120–180k, 180–250k, 250k+) + od/do inputs, sobe (1,2,3,4+; buckets <1.75/2.75/3.75),
kat (prizemlje ≤0, 1.–2., 3.+, "nije zadnji kat"), features (AND), quick toggles (novo 7 dana, pala cijena,
≥10 % ispod prosjeka, s fotografijom, s telefonom, bez agencija = no `prodavac==='agencija'` and empty
`agencija`, bez suvlasničkih udjela, samo natječaji i dražbe), površina od/do, zemljište od, €/m² do.
Active filters as removable chips above the list + "Očisti sve". Saved searches (name → query string, per
browser) as chips. "Kopiraj link s filterima". Phone: filter panel with sticky "Prikaži N nekretnina".

**Sorting:** select + direction toggle (↑/↓ with text like "najjeftinije prvo"): Po mojim željama, Najbolja
ponuda (ocjena), Datum objave, Cijena, Cijena po m², Odnos prema prosjeku, Površina, Okućnica/zemljište,
Broj soba, Pad cijene (30 dana), Broj izvora, Najrelevantnije (only while searching). Nulls always last;
ties: higher ocjena, then newer. The sorted-by value is highlighted on the card ("na tržištu 81 dan",
"−10.000 € (−11 %) prije 2 dana", "odgovara ti 93 % · garaža, 21 % ispod prosjeka", …).

**"Po mojim željama"** (per browser): priorities cycle off → ★ (1) → ★★ (2): ispod prosjeka, niža cijena,
veća površina, veća okućnica, više soba, tek objavljeno, pala cijena, any feature; "Izbjegavam" (−1):
za adaptaciju, prizemlje, zadnji kat, preko agencije, suvlasnički udio. Score = weighted mean of components
(0–1; percentile rank within the same vrsta for price/area/plot/rooms; prosjek = clamp(−vs/30, −0.5, 1);
novo = 1 − days/60; pad = posto/10) minus 0.25 per avoided trait, ×100. Setting a wish switches sort to it.

**Card:** photo (lazy, `referrerPolicy="no-referrer"`, fallback text), badges (Novo, Dražba/Natječaj, Udio,
Nestao, user mark), price, €/m², vs-average pill (green below −5 %, red above +5 %), facts line
(type · place · m² · sobe · kat · zemljište), highlighted value, deadline line (red ≤3 days), title,
snippet, "prije X · sources", buttons ⇄ compare, ★ favorit, ✕ odbaci. Pagination 40 + "Prikaži još".

**Detail (dialog, deep link `#n=<id>`):** photo, price, vs average, brojke (površina, zemljište, €/m²,
prosjek mjesta with count, sobe, kat, na tržištu, ocjena), features from description, auction/tender
warning with deadline and deposit, inactive warning, co-ownership warning, "Odgovara ti X %" with reasons,
price history, **cost calculator**, mark buttons (Favorit, Za obilazak, Kontaktirano, Odbačeno), compare
toggle, "Dodaj rok u kalendar (.ics)", all sources with prices, call button, Google Maps link
(kvart, naselje, općina), seller, score reasons, description (highlighted when searching).

**Cost calculator** (settings per browser, defaults: učešće 20 %, kamata 3,2 %, 30 god., provizija 3 % +
25 % PDV only for agency listings, bilježnik/odvjetnik/upis 500 €): porez na promet 3 % (0 for
"novogradnja od investitora", default from features), totals, cash upfront, loan, monthly annuity, total
interest; checkbox "prva nekretnina, < 45 god." shows possible refund (50 % of tax, or 50 % of VAT =
price×0.25/1.25×0.5 for new builds) with conditions; notes for auctions and shares; disclaimer.
Summary line in the collapsed header: "≈ X € odmah, rata ≈ Y €/mj.".

**Comparison (2–4):** floating bar "Usporedba: n" + Usporedi/Očisti; dialog `#usporedi=id1,id2` with a
table (sticky first column, horizontal scroll on phone), best value per row green (min/max per row),
rows incl. costs/cash/monthly from the calculator, "Odgovara ti" when wishes set; shareable link.

**Map** (`?prikaz=karta`, Popis | Karta toggle): one circle per neighbourhood/village for the current
filtered list (count inside, size ∝ √count, smaller on top), popup with middle price, €/m² for flats,
cheapest, "Prikaži popis" (filters to that place). Zoom < 12.5 merges city neighbourhoods into one
"Osijek" circle (click zooms to 13.5). Osijek without kvart = grey circle. Coordinates table:
`~/Documents/nekretnine-osijek/web/karta.js` (`KOORD`). Dark mode: inverted tiles.

**Deadlines:** banner when deadlines fall within 7 days ("Pogledaj rokove"); `.ics` export (single and
"svi u kalendar"), alarms −2 days and −2 hours, lines folded to RFC 5545.

**Sharing marks:** "Podijeli moje oznake" (Web Share API, else clipboard) → `#oznake=f.12.34~x.56`
(f favorit, o za_obilazak, k kontaktirano, x odbaceno); opening it shows a confirm banner; import only adds
marks where the user has none (never overwrites).

## Deployment (new)

1. Create an **orphan `main` branch** for the Next.js source (`git switch --orphan main`); `gh-pages` stays
   untouched and keeps serving the old site until cutover.
2. Backend `objava.py` (in `~/Documents/nekretnine-osijek/nekretnine/objava.py`) changes from "copy `web/`
   + force-push `gh-pages`" to "force-push **only `podaci.json`** to branch **`podaci`**" (single commit, same
   token, same masking of the token in errors), then send a `repository_dispatch` with `event_type: podaci`
   (`POST /repos/markoboras0712/nekretnine-osijek-web/dispatches`, same token; needs Contents: write).
   Config key `javno.grana` → `podaci`. Install with
   `cd ~/Documents/nekretnine-osijek && ./instaliraj.sh`. Keep `./nek test` green (24 tests; `test_javni_izvoz`
   must not push).
3. GitHub Actions workflow `.github/workflows/deploy.yml` on `main`: triggers `push` to `main`,
   `repository_dispatch` (`podaci`), `workflow_dispatch`. A `push` to `podaci` cannot trigger it: GitHub
   reads workflows from the pushed commit, and `podaci` holds only `podaci.json`. `repository_dispatch`
   runs from the default branch, so the default branch must be `main`. Steps: checkout `main` → `git fetch origin podaci && git show
   origin/podaci:podaci.json > public/podaci.json` → pnpm install (frozen) → format:check, typecheck, lint,
   test → `next build` (export to `out/`) → `actions/upload-pages-artifact` → `actions/deploy-pages`.
   Permissions `pages: write, id-token: write, contents: read`; concurrency group `pages`.
   Also a CI workflow like zoetrope's.
4. Cutover: the `podaci` branch must exist before the first deploy (seed it with the current
   `podaci.json`). Repo Settings → default branch = **`main`**; Settings → Environments → `github-pages`
   → allow `main` in its deployment branches (it only allows `gh-pages` from the legacy setup);
   Settings → Pages → Source = **GitHub Actions**; deploy objava change; check the site,
   `#n=<id>` links, and that hourly data pushes redeploy. Then the `gh-pages` branch can be deleted.
5. Local dev: copy the current `podaci.json` into `public/` (gitignored) and `pnpm dev`.
